# 도형의 닮음 & 피타고라스 정리 — 중2 수학 학습 웹 앱

빌드 과정 없이 정적 파일만으로 동작합니다. `index.html`을 브라우저로 열거나 GitHub Pages, Netlify 같은 정적 호스팅에 올리면 됩니다.

## 파일 구성

| 경로 | 설명 |
|---|---|
| `index.html` | 메인 앱 뼈대 |
| `css/style.css` | 대시보드 UI 스타일(반응형) |
| `js/config.js` | **구글 시트 웹 앱 URL 설정** |
| `js/data.js` | 단원, 개념 카드, 문제, 해설 데이터(문항 수정은 이 파일에서) |
| `js/app.js` | 세션, 화면 전환, 채점, 리포트, 구글 시트 전송 |
| `apps-script/Code.gs` | 구글 시트에 붙여 넣을 Apps Script 코드 |

## 구글 시트 연동 설정

1. 구글 드라이브에서 새 **구글 스프레드시트**를 만듭니다.
2. 메뉴에서 **확장 프로그램 → Apps Script**를 엽니다.
3. 기본 코드를 지우고 `apps-script/Code.gs` 내용을 붙여 넣은 뒤 저장(💾)합니다.
4. 위쪽 함수 선택 상자에서 **`setup`** 을 고르고 **실행**합니다.
   - 처음 실행하면 권한 승인 창이 뜹니다. **권한 검토 → 계정 선택 → (경고 화면에서) 고급 → 안전하지 않은 페이지로 이동 → 허용** 순서로 진행합니다. 본인이 만든 스크립트라 뜨는 일반적인 경고입니다.
   - 실행이 끝나면 시트에 **학습결과** 탭과 머리글이 만들어집니다.
5. **배포 → 새 배포 → 유형 선택(⚙) → 웹 앱**을 고릅니다.
   - 실행 사용자: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자** (학생은 구글 로그인 없이 전송합니다)
6. 발급된 `https://script.google.com/macros/s/…/exec` 주소를 복사해 `js/config.js`의 `SHEET_WEBAPP_URL`에 붙여 넣습니다.
7. **확인**: 복사한 주소를 브라우저 주소창에 열어 `"ok":true` 와 시트 이름이 보이면 성공입니다. 앱의 **최종 리포트** 화면에도 `🟢 구글 시트 연결됨`이 표시됩니다.

기록되는 내용

- **학습결과**: 리포트 화면에서 [구글 시트로 학습 결과 제출]을 누르면 기록됩니다(세션 ID, 시작·완료 시각, 학습 시간, 단원별 점수, 총점, 보상, OX·실험실 활동).

동작 방식과 안전장치

- 앱은 시트가 돌려준 **저장 완료 응답**까지 확인한 뒤에 "구글 시트에 저장되었습니다"라고 안내합니다. 응답을 받지 못하면 다시 한 번 보내고, 저장 여부를 선생님께 확인하라고 안내합니다.
- 예전 버전의 머리글이 있는 탭은 다음 기록 때 최신 머리글로 자동 갱신됩니다.
- 주소를 비워 두면 **데모 모드**로 동작합니다. 실제 전송 없이 완료 메시지만 표시됩니다.

> Apps Script 코드를 수정했다면 **배포 → 배포 관리 → ✏️ 수정 → 버전: 새 버전 → 배포**로 다시 배포해야 반영됩니다. 이렇게 하면 주소는 바뀌지 않습니다. (새 배포를 만들면 주소가 바뀌므로 config.js도 바꿔야 합니다.)

## 세션 및 데이터 초기화 정책

- 학습 기록은 `sessionStorage`에만 저장되고 서버나 `localStorage`에는 남지 않습니다.
- 페이지를 불러올 때마다 세션을 지우고 새 세션으로 시작합니다. 그래서 **새로고침**, **브라우저 종료 후 재접속** 중 어느 경우든 이전 점수와 진행 상황이 초기화됩니다.

## 학습 구성

| 단원 | 내용 | 문항 |
|---|---|---|
| 1 | 도형의 닮음과 성질 | 6 |
| 2 | 삼각형의 닮음 조건(SSS, SAS, AA) | 6 |
| 3 | 삼각형과 평행선 & 무게중심(2:1) | 7 |
| 4 | 닮은 도형의 넓이와 부피의 비 | 6 |
| 5 | 피타고라스 정리와 직각삼각형의 닮음 | 8 |

- 객관식과 단답형이 섞여 있고, 난이도는 기초·기본·응용 세 단계입니다.
- 제출하는 즉시 정답 여부와 해설이 표시되며, 한 문항은 한 번만 제출할 수 있습니다.
- 단답형은 단위(cm, °)를 붙이거나 생략해도 되고, 분수(18/5)·소수(3.6)·동치인 비(6:10 = 3:5)도 정답으로 처리합니다.

## 단원별 5단계 활동

각 단원은 아래 5단계로 진행되며, 상단 단계 표시줄에서 완료한 단계에 ✓가 붙습니다.

| 단계 | 내용 |
|---|---|
| 📘 개념 카드 | 요약 카드와 그림. 4단원은 모눈·쌓기나무 비교 그림, 5단원은 피타고라스 수 빈칸 채우기 미니 퀴즈 포함 |
| 🃏 카드 뒤집기 | 앞면 질문 → 눌러서 뒷면 답 확인 (단원별 4장) |
| ⭕ OX 퀴즈 | 한 문제씩 큰 O/X 버튼으로 풀고 즉시 해설 확인 (단원별 4문항) |
| 🧪 수학 실험실 | 슬라이더·드래그로 직접 실험하고 미션 달성 |
| ✏️ 문제 풀이 | 점수에 반영되는 객관식·단답형 문제 |

수학 실험실 미션

1. **닮음 확대·축소기**: 닮음비 k를 조절해 밑변을 9로 만들기
2. **닮은 삼각형 만들기**: 두 밑각을 조절해 AA 닮음 만들기
3. **무게중심 실험실**: ① 7단계 작도(자동 재생 지원) → ② 그림에서 성질 찾기 5과제(점·선분·영역 클릭) → ③ 꼭짓점 드래그 자유 실험
4. **쌓기나무 정육면체**: 부피가 27배인 정육면체 만들기
5. **피타고라스 수 탐험대**: 빗변이 자연수가 되는 수 3쌍 찾기

## 보상: 도토리 🌰와 칭찬도장

- **OX 퀴즈**, **미니 퀴즈**, **실험실 미션**, **풀이 문제**를 1개 맞히거나 달성할 때마다 도토리 1개를 받습니다.
- 도토리가 **10개** 모이면 도토리 10개를 쓰고 **칭찬도장 1개**로 자동 변환되며, 축하 모달이 뜹니다.
- 상단바에 보유 도토리(n/10 진행 막대)와 칭찬도장 개수가 항상 표시됩니다. 누르면 도토리 슬롯과 도장판 모달이 열립니다.
- OX·미니 퀴즈와 실험실 미션은 도토리만 주고 **총점에는 포함되지 않습니다**.
- 보상도 세션 데이터이므로 새로고침하면 초기화됩니다. 학습 결과를 제출하면 칭찬도장·보유/누적 도토리, OX 정답 수, 실험실 미션 완료 수가 시트에 함께 기록됩니다.
- 획득할 수 있는 도토리는 최대 63개(풀이 33 + OX 20 + 미니 퀴즈 5 + 실험실 5)이므로 칭찬도장은 최대 6개입니다.
